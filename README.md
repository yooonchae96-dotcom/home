# 선생님 홈 — 링크·웹앱·메모를 모아두는 개인 홈페이지 (MVP)

관리자(선생님)가 승인한 사람만 들어올 수 있는 개인 홈페이지입니다.

- 📅 **첫 화면 = 학사일정 달력 + 급식·시간표**: 왼쪽 큰 달력(나이스 학사일정), 날짜를 누르면 오른쪽 위에 그날 급식표, 오른쪽 아래에 그 주 시간표가 보입니다. 시간표는 **컴시간알리미 자료(comci.net)** 를 먼저 쓰고(학급별·선생님별 보기), 안 되면 나이스 시간표로 자동 전환됩니다. 관리자는 달력 위 **⚙ API 변경**에서 인증키·교육청코드·학교코드를 바꿀 수 있어요(학교가 바뀌어도 코드만 교체).
- 🔗 **링크 모음 탭**: 사진이 위, 제목이 아래에 뜨는 카드. 누르면 링크가 열립니다. (한 줄 최대 5개)
- 📁 **파일 모음 탭**: 어떤 파일이든(hwp, pdf, pptx, zip, 사진, 영상…) 올려 두고 내려받습니다. 파일 하나 500MB, 하루 총 5GB(.env에서 변경)까지. 넘으면 '오늘 가능한 용량'을 알려주는 경고창이 뜹니다.
- 🗂️ 모든 탭에서 **＋ 분류 추가**로 주제별 칸을 만들고, 카드를 **끌어서** 순서·분류를 바꿀 수 있습니다.
- 🧩 **웹앱 탭**: HTML 파일을 올리면 그 페이지 안에서 바로 실행됩니다.
- 📝 **메모 탭**: 메모를 쓰고 저장합니다.
- ➕ 관리자는 왼쪽에 **탭을 마음대로 추가**할 수 있습니다. (종류: 링크 모음 / 파일 모음 / 웹앱 / 메모)
- 🔒 모든 탭·링크·웹앱·메모마다 **공개범위**(나만 보기 / 승인받은 사람만 / 전체 공개)를 정합니다.
- 🛡️ 구글 로그인 → 관리자 승인 → 입장. 승인 전에는 '전체 공개' 자료만 볼 수 있습니다.
- 📄 로그인할 때 약관 동의, 화면 맨 아래에 이용약관·개인정보처리방침이 있습니다.

## 1단계. Firebase 설정 값 넣기 (.env)

1. https://console.firebase.google.com 에서 **jjinDB** 프로젝트를 엽니다.
2. 왼쪽 위 톱니바퀴 ⚙️ → **프로젝트 설정** → 아래 **내 앱** → 웹 앱(</>)의 `firebaseConfig` 값을 봅니다.
3. 이 폴더의 `.env.example` 파일을 복사해서 이름을 **`.env`** 로 바꾼 뒤, 메모장으로 열고 값을 채웁니다.

```
VITE_FIREBASE_API_KEY=여기에 apiKey
VITE_FIREBASE_AUTH_DOMAIN=여기에 authDomain
VITE_FIREBASE_PROJECT_ID=jjindb-e42fe
VITE_FIREBASE_STORAGE_BUCKET=여기에 storageBucket
VITE_FIREBASE_MESSAGING_SENDER_ID=여기에 messagingSenderId
VITE_FIREBASE_APP_ID=여기에 appId
VITE_ADMIN_EMAILS=선생님구글이메일@gmail.com
VITE_DAILY_UPLOAD_GB=5
```

> 예전에 만든 **kin 폴더의 .env** 가 있다면 그 안의 `VITE_FIREBASE_...` 여섯 줄을 그대로 복사해 오면 됩니다.
> `.env`는 깃허브에 올라가지 않습니다(.gitignore에 들어 있음).

## 2단계. 보안 규칙에 관리자 이메일 적기

`firestore.rules` 파일을 열어 맨 위의

```
return ['your-email@gmail.com'];
```

를 선생님 구글 이메일로 바꿉니다. (.env 의 VITE_ADMIN_EMAILS 와 똑같이)

그다음 Firebase 콘솔에서 규칙을 붙여 넣습니다.
- **Firestore Database → 규칙** 탭 → `firestore.rules` 내용 전체를 붙여 넣고 **게시**
- **Storage → 규칙** 탭 → `storage.rules` 내용 전체를 붙여 넣고 **게시**

(Firebase CLI를 쓰신다면 `firebase deploy --only firestore,storage` 한 줄로도 됩니다.)

## 3단계. 내 컴퓨터에서 실행해 보기

Antigravity(또는 VS Code) 터미널에서 이 폴더를 열고:

```
npm install
npm run dev
```

브라우저에서 `http://localhost:5173` 을 엽니다.
처음 관리자로 로그인하면 기본 탭 4개(링크 모음 / 파일 모음 / 웹앱 / 메모)가 자동으로 생깁니다.

### 처음 실행할 때 나올 수 있는 오류

- **"The query requires an index"** 라는 빨간 글씨가 콘솔(F12)에 뜨면 → 그 메시지 안의 **링크를 클릭**하면 Firebase가 인덱스를 만들어 줍니다. (2~3분 뒤 새로고침)
  또는 `firebase deploy --only firestore:indexes` 로 한 번에 만들 수 있습니다.
- **로그인 팝업이 안 뜨면** → 브라우저 주소창 오른쪽 팝업 차단 아이콘을 눌러 허용.
- **배포한 주소에서 로그인이 안 되면** → Firebase 콘솔 **Authentication → 설정 → 승인된 도메인**에 배포 주소(예: xxx.vercel.app)를 추가.

## 4단계. 깃허브 + Vercel 배포 (컴시간 시간표를 쓰려면 필수)

컴시간 시간표는 `api/comcigan.js` 라는 **서버 함수**가 comci.net 에서 자료를 받아 오는 방식이라, Vercel 에 배포해야 동작합니다.
(내 컴퓨터에서 `npm run dev` 로 실행 중일 때는 서버 함수가 없어서 자동으로 나이스 시간표를 보여 줍니다.
배포 없이 확인해 보고 싶으면 `npx vercel dev` 로 실행하면 서버 함수까지 같이 돌아갑니다.)

1. 깃허브에 **비공개(private)** 저장소를 만들고 이 폴더를 올립니다.
2. Vercel에서 그 저장소를 가져오기(Import) → **Environment Variables**에 `.env` 의 8줄을 하나씩 추가 → Deploy.
3. 3단계의 '승인된 도메인'에 Vercel 주소를 추가합니다.

## 사용 방법

| 하고 싶은 일 | 방법 |
|---|---|
| 달력에 내 일정 넣기 | 날짜 칸에 마우스를 올리면 나오는 작은 **+** 버튼 (기간·종류·메모). 초록색으로 표시되고, 삭제하기 전까지 DB(events)에 계속 남아요. 일정을 누르면 수정·삭제 |
| 학사일정 API 넣기·바꾸기 | 첫 화면(학사일정) 오른쪽 위 **⚙ API 변경** → 인증키, 시도교육청코드(서울 B10), 행정표준코드 → 저장(저장 전에 자동 확인) |
| 컴시간 시간표 연결 | 같은 창의 **컴시간알리미 학교 검색어** (비우면 학교 이름으로 검색). 시간표 칸의 **학급별 / 선생님별** 버튼으로 전환 |
| 교시 시간 맞추기 | `src/components/CalendarHome.jsx` 의 `PERIOD_TIMES` |
| 탭 추가 | 왼쪽 메뉴 맨 아래 **＋ 탭 추가** → 이름·종류·아이콘·설명·공개범위 |
| 탭 이름 바꾸기·삭제 | 탭 오른쪽의 ✎ |
| 링크 카드 만들기 | 링크 탭에서 **＋ 링크 추가** → 제목·주소·사진 |
| HTML 웹앱 올리기 | 웹앱 탭에서 **＋ HTML 올리기** → 목록에서 **실행** |
| 파일 올리기 | 파일 모음 탭에서 **＋ 파일 올리기** → **⬇ 내려받기** |
| 분류(주제) 만들기 | 각 탭 제목 옆 **＋ 분류 추가**, 소제목 옆 ✎ 로 이름 바꾸기·삭제 |
| 카드 순서·분류 옮기기 | 카드를 누른 채 끌어서 다른 카드 앞이나 분류 칸에 놓기 |
| 분류 통째로 옮기기 | 분류 소제목 줄 아무 곳이나 누른 채 끌어서 다른 분류 위에 놓기 (글씨 클릭은 이름 편집) |
| 파일 하나 한도 바꾸기 | `src/components/FilesTab.jsx` 의 `MAX_FILE_MB`(500) 와 `storage.rules` 의 `500 * 1024 * 1024` 를 같이 수정 |
| 하루 업로드 총량 바꾸기 | `.env` 의 `VITE_DAILY_UPLOAD_GB` (Vercel이면 환경변수도) |
| 메모 쓰기 | 메모 탭에서 **＋ 새 메모** → 저장 |
| 이용자 승인 | 왼쪽 메뉴 **관리자** → 승인 대기 목록에서 **승인** |
| 약관 문구 고치기 | `src/legal.js` |
| 사이트 이름 바꾸기 | `src/legal.js` 의 `SITE_NAME` |
| 색 바꾸기 | `src/index.css` 맨 위 `--navy` 값 |

### 공개범위 뜻
- **나만 보기**: 쓴 사람과 관리자만
- **승인받은 사람만**: 관리자가 승인한 모든 사람 (기본값)
- **전체 공개**: 로그인만 하면 승인 전에도 '승인 대기' 화면에서 볼 수 있음

### 이번 MVP에서 뺀 것 (나중에)
- HTML 파일은 900KB 이하만 (더 큰 파일은 Storage 업로드로 바꾸면 됨)
- 탭 순서 끌어서 바꾸기, 메모 검색, 이용자 여러 명이 동시에 같은 메모 편집
